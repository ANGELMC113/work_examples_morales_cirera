This repository contains some projects developed by my fellow university students and I. Some of them will require internet connection to download data (but do not worry, those are safe). Most of them have their reports in English, but some are in Spanish or Catalan.

The projects have been distributed on three general topics:

-   [Data Analysis and visualization](./Data%20analysis%20and%20visualization/)

-   [Distributed and high performance computing](./Distributed%20and%20high%20performance%20computing/)

-   [Machine learning](./Machine%20learning/)

Here is a brief explanation of each project:

-   [Data Visualization with Python Notebook](./Data%20analysis%20and%20visualization/Data%20Visualization%20with%20Python%20Notebook/), about some grants cancelled in the US with a variety of graphical approaches. The Python Notebook is provided.

-   [Locality-Sensitive Hashing Experiments](./Data%20analysis%20and%20visualization/Locality-Sensitive%20Hashing%20Experiments/): a study of how the parameters of locality-sensitive hashing affect its performance, focused on its usage to detect near-duplicate documents on a big corpus. I have included the report and Python Notebook.

-   [Multivariate Data Analysis with R](./Data%20analysis%20and%20visualization/Multivariate%20Data%20Analysis%20with%20R/): an analysis of a data set about cars and the insights of their variables. I have provided the pdf report.

-   [Rutes_i_Monuments](https://github.com/ANGELMC113/rutes_i_monuments) is a quite extensive package which allows to gather geospatial data and create maps and KML files to explore it. It uses KMeans, a clustering algorithm, in order to create graphs from the data, which allows to search for routes between historical monuments. I have provided the documentation, the Python files, some tutorials, tests and the data of those to make executions quicker.

-   [Time Series Data Analysis with R](./Data%20analysis%20and%20visualization/Time%20Series%20Data%20Analysis%20with%20R/), studies the behavior and tendency of the exports of Spain. I've delivered the pdf report.

-   [Distributed Computing Experiments on MareNostrum 5](./Distributed%20and%20high%20performance%20computing/Distributed%20Computing%20Experiments%20on%20MareNostrum%205/), a study of the scalability and efficiency of some kernels using OpenMP vs MPI, performed on the Barcelona Supercomputing Center's MareNostrum 5. You have access to the code, the logs and the report.

-   [Spark Experiments on AWS](./Distributed%20and%20high%20performance%20computing/Spark%20Experiments%20on%20AWS/), about the efficiency of Spark handling big data sets, performed on Amazon Web Services EC2 instances. I've included the code, the logs and the report.

-   [Machine Learning for Binary Classifications](./Machine%20learning/Machine%20Learning%20for%20Binary%20Classifications/) contains a Python Notebook with an a wide variety of shallow algorithms for binary classification. The goal was to properly classify liver patients by using some other variables, with a little data set to use. I've also handed the pdf report and the necessary data.

Feel free to contact me for any extra information. You can freely read and execute the provided files.
